# 倍の見方ラボ

小学4年生「倍の見方」の単元を、ゲーミフィケーションつきで
段階的にマスターできる学習アプリ。

比較量（くらべられる量）＝ 基準量（もとにする量）× 倍 の関係を、
テープ図・文章題・エラーハンター・本番テストモードで多角的に学ぶ。

## モジュール（単元の知識・技能を段階的に網羅）

| モジュール | 内容 |
|---|---|
| 基礎：倍の見方 | もとにする量・倍・くらべられる量の関係を、小さい整数とテープ図で入門 |
| 何倍かを もとめる | くらべられる量 ÷ もとにする量 ＝ 倍 |
| 何倍かにあたる量 | もとにする量 × 倍 ＝ くらべられる量 |
| もとにする量 | くらべられる量 ÷ 倍 ＝ もとにする量 |
| 割合で くらべる | ゴムA・B型：2つの変化を「差」ではなく「倍」でくらべる |
| ことばの もんだい | どんな関係かを選んでから計算する、しき選択→計算の段階入力 |
| エラーハンター | 基準量と比較量の取り違え・差での計算・×÷の取り違え等の頻出誤答の発見・修正・理由の言語化 |
| 本番テストモード | 表（知識・技能100点）＋いかそう算数（参考）を通しで挑戦 |

## ゲーミフィケーション

- きょうの目標リング（5/10/15/20問・タップで切替）
- 連続ノーミス記録・スキル別の熟達バー（5問連続ノーミスでMAX）
- ごほうびバッジ（累計・ノーミス・テスト得点・モジュール別デビュー／マスター・最終称号「【倍の見方】神」）
- バッジ獲得率で解放される特別テーマ（深海50%・極光75%・宇宙神100%）＋和・マトリックス
- おまかせモード（正答率にもとづく適応難易度。2問連続ノーミスでレベルアップ）
- ふくしゅうコーナー（正答率が低いスキルをホームで提案）
- やさしい効果音（Web Audio合成・設定でOFF可）とプロセス称賛メッセージ
- 学習のきろく（モジュール別クリア数・履歴・テストの答案詳細）

進捗・設定は localStorage に保存されます。

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
