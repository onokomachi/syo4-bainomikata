# 倍の見方ラボ

小学4年生「倍の見方」の単元を、ゲーミフィケーションつきで
段階的にマスターできる学習アプリ。

比較量（くらべられる量）＝ 基準量（もとにする量）× 倍 の関係を、
二重数直線・文章題・エラーハンター・本番テストモードで多角的に学ぶ。

## 解答の段階（実際の単元テストの採点に合わせる）

学習指導要領は「**図や式などを用いて**、二つの数量の関係の比べ方を考察する」ことを求めており、
単元テストでも配点の6割が図と式にふられている（図30点・式30点・答え25点・「1とみると」10点・判断5点）。
さらに「式の採点基準：計算の答えが誤っていても5点を配点してよい」と、式と答えは独立に採点される。

そのため答えの数値だけを判定せず、次の段階に分けて解く。

1. **図** — 二重数直線（テープ図＋倍の目もり）の□を順にうめる。「もとにする量を1とみる」をここで体で覚える
2. **式** — どんな計算になるかを選ぶ（もとにする量を求める回は □×5＝750 の関係式を先に立てる）
3. **答え** — 計算して答える
4. **1とみると** — 「◯を1とみると△はいくつにあたるか」を別に問う

## モジュール（単元の知識・技能を段階的に網羅）

| モジュール | 内容 |
|---|---|
| 基礎：倍の見方 | もとにする量・倍・くらべられる量の関係を、小さい整数と二重数直線で入門（図→答え） |
| 何倍かを もとめる | くらべられる量 ÷ もとにする量 ＝ 倍（図→式→答え） |
| 何倍かにあたる量 | もとにする量 × 倍 ＝ くらべられる量（図→式→答え） |
| もとにする量 | くらべられる量 ÷ 倍 ＝ もとにする量（図→関係式→式→答え） |
| 割合で くらべる | ゴムA・B型：2つの変化を「差」ではなく「倍」でくらべる。差は児童自身に計算させてから倍へ進み、「大きい方／小さい方」を入れかえて問う |
| ことばの もんだい | どんな関係かを選んでから計算する、しき選択→計算の段階入力 |
| エラーハンター | 基準量と比較量の取り違え・差での計算・×÷の取り違え等の頻出誤答の発見・修正・理由の言語化 |
| 本番テストモード | 表（知識・技能100点）＋いかそう算数（参考）を通しで挑戦 |

## ゲーミフィケーション

- きょうの目標リング（5/10/15/20問・タップで切替）
- 連続ノーミス記録・スキル別の熟達バー（5問連続ノーミスでMAX）
- ごほうびバッジ（累計・ノーミス・テスト得点・モジュール別デビュー／マスター・最終称号「【倍の見方】神」）
- バッジ獲得率で解放される特別テーマ（バブル25%・桜吹雪50%・スノーワールド75%・時空神100%）＋ノーマル・マトリックス
- おまかせモード（正答率にもとづく適応難易度。2問連続ノーミスでレベルアップ）
- ふくしゅうコーナー（正答率が低いスキルをホームで提案）
- やさしい効果音（Web Audio合成・設定でOFF可）とプロセス称賛メッセージ
- 学習のきろく（モジュール別クリア数・履歴・テストの答案詳細）

進捗・設定は localStorage に保存されます。

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
